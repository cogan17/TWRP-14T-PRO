# 🦊 OrangeFox for Xiaomi 14T Pro

[← Back to README](../../README.en.md) · <img src="https://flagcdn.com/24x18/id.png" width="22" alt=""> [Bahasa Indonesia](README.md)

OrangeFox is a TWRP-based recovery with a new look and extra features. Here it is built from **the same device tree** as TWRP, so its hardware support, modules and decryption are the same proven ones.

> TWRP and OrangeFox **live in the same place** (`vendor_boot`). Only one is installed at a time, and each can replace the other whenever you like.

---

## TWRP or OrangeFox?

| | TWRP | OrangeFox |
|---|---|---|
| Look | classic | modern, themeable |
| File manager | basic | full (multi-select, zip/unzip, editor) |
| KernelSU modules from recovery | ❌ (manually via File Manager) | ✅ **KernelSU modules** menu |
| Size | smaller | larger, still fits |
| Track record on this phone | tested the longest | new (v1.0) |

Not sure? Use **TWRP**. Want more features? Try **OrangeFox** — going back to TWRP takes one step.
