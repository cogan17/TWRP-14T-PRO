OrangeFox Recovery

Panduan OrangeFox
Xiaomi 14T Pro (rothko)

@OFOX_VER@ · firmware @VERSION@ · oleh Cogan17

Buku ini memandu kamu langkah demi langkah: memasang OrangeFox, masuk ke OrangeFox, membuka data, mengenal menunya, mencadangkan (backup), dan kembali ke TWRP atau stok kapan saja. Tidak perlu jadi ahli — ikuti saja urutannya.

1. Yang perlu disiapkan 2. Memasang OrangeFox 3. Masuk ke OrangeFox 4. Membuka data (pola/sandi) 5. Kenali menunya 6. Backup & restore 7. Kembali ke TWRP atau stok 8. Ambil log kalau bermasalah 9. Aturan penting

1. Yang perlu disiapkan

  • Versi firmware di nama paket harus sama dengan HyperOS di HP (Setelan → Tentang ponsel). Paket ini untuk @VERSION@.
  • Bootloader HP sudah ter-unlock.
  • Tanpa PC: cukup TWRP yang sudah terpasang.
  • Lewat PC: komputer Windows, kabel USB yang bagus, dan folder platform-tools (berisi adb.exe & fastboot.exe). Ekstrak semua isi paket ke folder itu.
Baterai HP minimal 50% sebelum mulai, biar aman.

2. Memasang OrangeFox

Dari TWRP (tanpa PC — paling mudah):

  1. Salin zip paket ini ke HP. Tidak perlu diekstrak.
  2. Masuk TWRP → Install → pilih zip itu → geser.
  3. Tunggu tulisan Berhasil → Reboot → Recovery.

Zip mengecek HP dan file, menulis OrangeFox ke vendor_boot, lalu memeriksa ulang. Kalau ada yang tidak cocok, tidak ada yang ditulis.

Lewat PC (FASTBOOT):

  1. Matikan HP. Tahan Power + Volume Bawah sampai muncul tulisan FASTBOOT.
  2. Sambungkan HP ke komputer dengan kabel.
  3. Klik dua kali 1-PASANG-ORANGEFOX.bat, ikuti petunjuk sampai BERHASIL.

Update OrangeFox: di OrangeFox buka Berkas → ketuk zip paket versi baru → Pasang ZIP → geser.

Data di HP tidak dihapus oleh semua cara di atas.

3. Masuk ke OrangeFox

  1. Matikan HP sampai benar-benar mati.
  2. Tahan Volume Atas + Power bersamaan.
  3. Saat logo Mi muncul, lepas tombol Power tapi tahan terus Volume Atas sebentar, sampai OrangeFox terbuka.
Masuk recovery harus dari kondisi HP mati + tombol, bukan lewat perintah "reboot recovery".

4. Membuka data (pola / sandi)

  • Pengguna utama (0): gambar pola yang sama seperti di layar kunci HP — sekali saja, teliti. Kalau benar, data, foto dan Download langsung terbuka.
  • XSpace / Ruang Kedua (999): profil terpisah dengan sandi sendiri. Masukkan kalau kamu memakainya; kalau tidak, lewati saja.
Jangan coba berkali-kali kalau lupa. Salah berulang bisa mengunci sementara.

Setelah terbuka, coba layar sentuh, lalu Pilihan → Mulai ulang → System untuk memastikan Android menyala normal.

5. Kenali menunya

Di bawah layar ada 4 tab: Berkas, Cadangkan, Bersihkan, Pilihan.

Di OrangeFox, "Muat" artinya Mount, bukan memasang file. Memasang file selalu lewat Berkas: ketuk file-nya.
  • Berkas — file manager. Ketuk .zip → Pasang ZIP; ketuk .img → Flash Image File → pilih partisi (recovery → vendor_boot, kernel → boot).
  • Cadangkan — membuat dan memulihkan backup (lihat bagian 6).
  • Bersihkan — hanya Dalvik / ART Cache dan Cache yang aman. Data, Metadata, Penyimpanan Internal dan Format Data menghapus isi HP.
  • Pilihan — Muat (Mount & MTP), ADB & Sideload, Mulai ulang, Modul KernelSU (mematikan modul yang membuat bootloop), Salin Log ke kartu SD.

6. Backup & restore

  1. Buka tab Cadangkan → Cadangan Baru.
  2. Pilih partisi. Sebelum bereksperimen, cadangkan minimal boot dan init_boot.
  3. Geser untuk memulai. Pilih Penyimpanan untuk menyimpan ke internal atau USB OTG.

Memulihkan: ketuk backup yang ada → Pulihkan.

  • Backup Data tidak berisi foto dan Download (penyimpanan internal). Salin itu ke PC terpisah.
  • Restore Data hanya ke versi HyperOS yang sama dengan saat backup.
  • Jangan reset pabrik dulu sebelum restore — Pulihkan sudah mengosongkan Data sendiri.
Simpan salinan backup ke PC/flashdisk juga, biar aman kalau HP bermasalah.

7. Kembali ke TWRP atau stok

Kembali ke TWRP (@TWRP_VER@ ikut di paket ini):

  • Lewat PC: HP di FASTBOOT → klik dua kali 3-KEMBALI-KE-TWRP.bat.
  • Di OrangeFox: Berkas → ketuk @TWRP_IMG@ → Flash Image File → vendor_boot → geser. Atau ketuk zip paket TWRP → Pasang ZIP.

Kembali ke stok (tanpa recovery kustom, data tidak dihapus):

  • Lewat PC: HP di FASTBOOT → klik dua kali 2-KEMBALIKAN-STOK.bat.
  • Di OrangeFox: Berkas → ketuk @STOCK_IMG@ → Flash Image File → vendor_boot → geser → Mulai ulang → System.
Wajib vendor_boot, jangan boot / init_boot. File STOK-… menghapus recovery kustom — jangan tertukar dengan OrangeFox-… atau TWRP-….
HP terus masuk recovery atau bootloop? Paksa mati (tahan Power ~15 detik), tahan Power + Volume Bawah sampai FASTBOOT, lalu jalankan .bat dari PC.

8. Ambil log kalau butuh bantuan

  • Di HP: Pilihan → Salin Log ke kartu SD. Log tersimpan di folder Fox di penyimpanan internal. Lakukan sebelum reboot — log hilang setelah HP menyala ulang.
  • Lewat PC: 3-AMBIL-LOG.bat atau, untuk bootloop, 4-LOG-BOOTLOOP.bat dari paket TWRP.

Kirim log beserta foto layar saat error. Jangan menebak — log menunjukkan penyebabnya.

9. Aturan penting (baca ini!)

JANGAN reset pabrik / Bersihkan Data / Format Data dari recovery. Di Android 15/16 itu memicu FRP: APK tidak bisa dipasang dengan cara biasa, dan tandanya tidak hilang tanpa penyiapan awal. Kalau perlu reset, pakai Setelan HyperOS → Tentang ponsel → Reset pabrik.
Terlanjur reset dari recovery? Saat penyiapan awal meminta akun Google, jangan tinggalkan layar itu untuk restore Data. Masuk dengan akun Google yang sama — itu satu-satunya kesempatan resmi mematikan FRP. Setelah Data di-restore, layar itu tidak muncul lagi.
Menu yang tidak boleh dipakai di HP ini (belum teruji dengan vendor_boot dua bagian, bisa membuat recovery atau Android tidak bisa boot):
  • Flash OrangeFox saat ini dan reflash otomatis (sudah disembunyikan).
  • Fix recovery bootloop, Inject OrangeFox.
  • Pasang Magisk / KernelSU dari recovery, dan menu OTA OrangeFox.
  • Selalu backup data penting sebelum bereksperimen.
  • Pasang hanya file untuk rothko (14T Pro) — jangan dari HP lain.
  • Jangan pakai "FRP unlock tool" pihak ketiga dan jangan mengutak-atik partisi frp.
