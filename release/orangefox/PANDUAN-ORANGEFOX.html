1. Kenalan dengan OrangeFox

OrangeFox adalah recovery turunan TWRP: tampilan modern, file manager lengkap, pengelola modul KernelSU, dan tema yang bisa diganti. Di HP ini OrangeFox dibangun dari device tree yang sama dengan TWRP.

  • TWRP dan OrangeFox tinggal di tempat yang sama (vendor_boot). Yang terpasang hanya satu; memasang yang satu otomatis menggantikan yang lain.
  • vendor_boot juga berisi modul yang dipakai Android saat boot normal. Karena itu image harus untuk versi HyperOS yang sama persis: paket ini untuk @VERSION@.
  • Data, foto dan aplikasi tidak tersentuh saat memasang, mengganti atau melepas OrangeFox.

2. Persiapan & cek file

  • Versi HyperOS (Setelan → Tentang ponsel) harus @VERSION@.
  • Bootloader sudah ter-unlock. Baterai minimal 50%. Foto dan Download sudah disalin ke PC.
  • Tanpa PC: cukup TWRP atau OrangeFox yang sudah terpasang.
  • Lewat PC: komputer Windows, kabel USB yang bagus, dan folder platform-tools (berisi adb.exe & fastboot.exe). Ekstrak semua isi paket ke folder itu.

Pastikan file utuh. Unduhan yang terputus membuat zip rusak: ZArchiver menulis "Kesalahan Data" dan image hasil ekstrak lebih kecil dari 64 MB. Ketiga .img di paket ini masing-masing 64,00 MB. Cek SHA256 zip di Termux:

sha256sum PAKET-OrangeFox-*.zip

Hasilnya harus sama dengan halaman rilis. SHA256 tiap image ada di BACA-SAYA.txt; di OrangeFox bisa dicek lewat Berkas → tekan lama file → Cheksum.

Image yang ukurannya bukan 64 MB atau SHA256-nya beda: jangan di-flash. Unduh ulang dari Releases (bukan dari tab Actions). Ekstrak ke folder baru supaya tidak tercampur.

3. Memasang OrangeFox

Dari TWRP (tanpa PC — paling mudah):

  1. Salin zip paket ini ke HP. Tidak perlu diekstrak.
  2. Masuk TWRP → Install → pilih zip itu → geser.
  3. Tunggu tulisan Berhasil → Reboot → Recovery.

Zip mengecek HP dan file, menulis OrangeFox ke vendor_boot, lalu memeriksa ulang. Kalau ada yang tidak cocok, tidak ada yang ditulis.

Dari OrangeFox (update versi): Berkas → ketuk zip paket versi baru → Pasang Zip → Gesek untuk Menginstal → Pilihan → Mulai ulang → Pemulihan.

Lewat PC (FASTBOOT):

  1. Matikan HP. Tahan Power + Volume Bawah sampai muncul tulisan FASTBOOT.
  2. Sambungkan HP ke komputer dengan kabel.
  3. Klik dua kali 1-PASANG-ORANGEFOX.bat, ikuti petunjuk sampai BERHASIL.

Setelah memasang: masuk OrangeFox, buka dengan pola, coba layar sentuh dan buka Berkas, lalu Pilihan → Mulai ulang → Sistem untuk memastikan Android menyala normal.

Data di HP tidak dihapus oleh semua cara di atas.

4. Masuk ke OrangeFox

  1. Matikan HP sampai benar-benar mati.
  2. Tahan Volume Atas + Power bersamaan.
  3. Saat logo Mi muncul, lepas tombol Power tapi tahan terus Volume Atas sebentar, sampai OrangeFox terbuka.

HP sudah root? Dari Termux: su -c 'reboot recovery' — hanya kalau OrangeFox yang terpasang sudah terbukti jalan.

"reboot recovery" meninggalkan tanda di partisi misc. Kalau recovery-nya rusak, HP terus kembali ke recovery yang rusak itu. Jalan keluar: tahan Power ~15 detik sampai mati → Power + Volume Bawah → FASTBOOT → .bat dari PC.

Keluar dari OrangeFox: Pilihan → Mulai ulang → Sistem.

5. Membuka data (pola)

Muncul tulisan "Partisi Data dienkripsi" dan permintaan pola.

  • Pengguna utama (0): gambar pola layar kunci — sekali saja, teliti. Muncul Mencoba Dekripsi lalu Deskripsi sukses!; foto dan Download langsung terbuka.
  • XSpace / Ruang Kedua (999): profil terpisah dengan sandi sendiri. Kalau tidak dipakai, tekan kembali untuk melewati.
  • Terlewat? Buka nanti lewat Pilihan → Lainnya → Dekripsi data (atau Dekripsi Pengguna).
Pola gagal! berulang kali bisa mengunci sementara. Jangan dicoba terus — ambil log (bagian 17).

Ganti pola di Android? OrangeFox otomatis memakai pola yang baru.

6. Layar & navigasi

  • Bilah bawah berisi 4 tab: Berkas, Cadangkan, Bersihkan, Pilihan.
  • Tombol navigasi paling bawah: kembali, beranda, sembunyikan bilah.
  • Ikon roda gigi di atas tab Pilihan = Pengaturan (bagian 13).
  • Tindakan berisiko selalu minta geser (Gesek untuk Mengonfirmasi) — sebelum digeser, belum ada yang terjadi.
Di OrangeFox, "Muat" artinya Mount, bukan memasang file. Memasang file selalu lewat Berkas: ketuk file-nya.

Opsi di Pasang Zip: Tambahkan ke antrian (maks 10 zip) dan Mulai ulang setelah pemasangan selesai ✅. Flash Ulang OrangeFox setelah flashing ROM, Suntikkan OrangeFox, Nonaktifkan vbmeta AVB2.0, Tambah Magisk ⛔ — kalau muncul, biarkan mati.

Tekan lama file/folder: Buka sebagai, Salin, Pindah, Ubah Nama, Hapus ⚠️, Kompres, Buka paket arsip, Cheksum, Informasi. Tekan lama lalu ketuk file lain untuk memilih banyak (Urutan aksi). Atur Perizinan, Edit File di nano dan Buka terminal disini ⚠️ hanya untuk yang paham.

Lokasi penting: penyimpanan internal /sdcard · backup Fox/BACKUPS · log Fox/logs.

8. Cadangkan — backup & restore

Membuat backup:

  1. Tab Cadangkan → Cadangan Baru.
  2. Nama: biarkan otomatis atau ketik sendiri.
  3. Centang Partisi: minimal boot, init_boot, vendor_boot; tambah Data kalau perlu.
  4. Geser untuk mencadangkan → tunggu Pencadangan selesai.

Pilih Penyimpanan menentukan tempat simpan (internal atau USB OTG). Hasilnya di Fox/BACKUPS. Aktifkan Enkripsi boleh, tapi kata sandinya wajib diingat.

Memulihkan: tab Cadangkan → ketuk backup → centang partisi → Geser untuk Mengembalikan → tunggu Pemulihan selesai → Mulai ulang → Sistem. Boot pertama bisa lama.

  • Backup Data tidak berisi foto dan Download. Salin itu ke PC terpisah.
  • Restore Data hanya ke versi HyperOS yang sama dengan saat backup.
  • Jangan reset pabrik / Bersihkan Data dulu sebelum restore — restore sudah mengosongkan Data sendiri.
  • Setelah restore, aplikasi kembali seperti tanggal backup; modul root kadang perlu dipasang ulang.
Simpan salinan backup ke PC/flashdisk juga, biar aman kalau HP bermasalah.

11. Modul KernelSU — bootloop karena modul

  1. Masuk OrangeFox, buka dengan pola.
  2. Pilihan → Modul KernelSU → tunggu daftar modul.
  3. Ketuk modul yang dicurigai → matikan Aktif, atau Lewati mount, atau Hapus modul mulai ulang selanjutnya.
  4. Mulai ulang → Android menyala tanpa modul itu.

Ragu yang mana? Matikan yang terakhir dipasang, lalu satu per satu.

12. Kernel & root

Sebelum apa pun: Cadangkan boot dan init_boot, salin ke PC.

  • Kernel (AnyKernel3 zip): Berkas → ketuk zip → Gesek untuk Menginstal → Mulai ulang → Sistem.
  • Root (init_boot hasil patch): patch init_boot.img stok di aplikasi manager (KernelSU/Magisk) di Android → Berkas → ketuk hasilnya → Pasang Image → init_boot → geser.
  • Bermasalah: Cadangkan → backup tadi → centang boot/init_boot → Geser untuk Mengembalikan.
Jangan pakai Pasang Magisk/KernelSU dari menu OrangeFox. Aplikasi manager root harus cocok dengan varian kernel yang terpasang.

13. Pengaturan OrangeFox

Buka lewat ikon roda gigi di tab Pilihan.

  • Umum ✅ — file tersembunyi, deteksi jenis file, Mode pemulihan performa tinggi. Opsi flash ROM (vbmeta, Flash Ulang/Suntikkan OrangeFox) ⛔ biarkan mati.
  • OTA & ROM ⛔ — jangan diubah (untuk ROM kustom, bukan HyperOS stok).
  • Kustomisasi ✅ — tema, warna aksen, font, splash, bilah navigasi.
  • Keamanan ⚠️ — mengunci OrangeFox dengan PIN/sandi. Tidak perlu; lupa sandi berarti terkunci dari recovery sendiri.
  • Tampilan, Getaran ✅ — kecerahan, batas waktu layar, getaran.
  • Cadangkan ✅ — kompresi, verifikasi digest, partisi Backup Cepat.
  • Daerah ✅ — Zona Waktu (UTC +7) Bangkok, Hanoi, Jakarta, format 24 jam, Bahasa.

Setel ulang ke default hanya mengembalikan pengaturan OrangeFox — data HP tidak tersentuh.

14. Update HyperOS

Update HyperOS menimpa vendor_boot, jadi OrangeFox hilang setelah update — itu wajar.

  1. Backup dulu (file pribadi ke PC, partisi boot/init_boot/vendor_boot).
  2. Kembali ke stok (bagian 15) — OTA sering gagal kalau partisi masih termodifikasi.
  3. Update dari Setelan HyperOS. Jangan wipe — data ikut terbawa.
  4. Pasang OrangeFox versi yang cocok dengan HyperOS baru.
Jangan pakai menu OTA OrangeFox untuk HyperOS stok. Jangan restore Data dari versi HyperOS lama.

15. Kembali ke TWRP atau stok

Kembali ke TWRP (@TWRP_VER@ ikut di paket ini):

  • Lewat PC: HP di FASTBOOT → klik dua kali 3-KEMBALI-KE-TWRP.bat.
  • Di OrangeFox: Berkas → ketuk @TWRP_IMG@ → Pasang Image → vendor_boot → geser. Atau ketuk zip paket TWRP → Gesek untuk Menginstal.

Kembali ke stok (tanpa recovery kustom, data tidak dihapus):

  • Lewat PC: HP di FASTBOOT → klik dua kali 2-KEMBALIKAN-STOK.bat.
  • Di OrangeFox: Berkas → ketuk @STOCK_IMG@ → Pasang Image → vendor_boot → geser → Mulai ulang → Sistem.
Wajib vendor_boot, jangan boot / init_boot. File STOK-… menghapus recovery kustom — jangan tertukar dengan OrangeFox-… atau TWRP-….
HP terus masuk recovery atau bootloop? Paksa mati (tahan Power ~15 detik), tahan Power + Volume Bawah sampai FASTBOOT, lalu jalankan .bat dari PC.

16. Reset pabrik & FRP

JANGAN reset pabrik / Bersihkan Data / Format Data dari recovery. Di Android 15/16 itu memicu FRP: APK tidak bisa dipasang lewat pemasang bawaan (Play Store, MT Manager dengan root dan adb install tetap bisa). Kalau perlu reset, pakai Setelan HyperOS → Tentang ponsel → Reset pabrik.
  • Terlanjur reset dari recovery? Saat penyiapan awal meminta akun Google, jangan tinggalkan layar itu untuk restore Data. Masuk dengan akun Google yang sama.
  • Terbukti di HP owner (30 Okt 2026): flash ROM fastboot stok penuh dengan Mi Flash clean all (bukan clean all and lock), lalu login akun Google sendiri saat penyiapan, menghilangkan FRP. Data terhapus — pindahkan backup ke PC dulu. Setelah itu pasang ulang TWRP/OrangeFox, kernel dan root.
Jangan pakai Remove FRP di OrangeFox, "FRP unlock tool" pihak ketiga, atau mengutak-atik partisi frp.

17. Masalah & log

  • Di HP: Pilihan → Salin Log ke kartu SD → file ada di Fox/logs. Lakukan sebelum reboot — log hilang setelah HP menyala ulang. Dekripsi gagal? Ada lastrecoverylog.log di folder yang sama.
  • Lewat PC: 3-AMBIL-LOG.bat atau, untuk bootloop, 4-LOG-BOOTLOOP.bat dari paket TWRP.

18. Daftar larangan (baca ini!)

  • Reset pabrik, Bersihkan Data, Metadata, Penyimpanan Internal, Format Data dari recovery.
  • Menulis recovery ke boot/init_boot; Instal Ramdisk; Flash ke kedua slot; Beralih slot.
  • Flash OrangeFox saat ini, Flash Ulang OrangeFox setelah flashing ROM, Suntikkan OrangeFox, Perbaiki Bootloop Pemulihan — belum teruji dengan vendor_boot dua bagian.
  • Pasang Magisk / KernelSU dari recovery, Nonaktifkan vbmeta / DM-Verity / Enkripsi Paksa, init.d, menu OTA.
  • Remove FRP, "FRP unlock tool", partisi frp.
  • File untuk HP lain atau versi HyperOS lain.

Selalu backup data penting sebelum bereksperimen.
